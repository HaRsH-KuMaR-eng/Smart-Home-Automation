# 💡 Smart Light Automation

An IoT-based **Smart Light Automation System** that allows users to remotely control a light using an **Android application** over Wi-Fi.

## 📌 Features

* 💡 **Light ON/OFF Control** through an Android application
* 📱 Built the Android interface using **MIT App Inventor**
* 📡 Uses **ESP8266** for Wi-Fi-based communication
* 🔌 Uses a **Relay Module** to control the light
* ⚡ Enables wireless and remote light control
* 🖥️ Simple and user-friendly interface

## 🛠️ Tech Stack

* **MIT App Inventor** – Android application development
* **ESP8266** – Wi-Fi communication and control
* **Arduino IDE** – ESP8266 programming
* **Wi-Fi** – Wireless communication
* **Relay Module** – Light switching
* **Embedded Systems** – Hardware control

## 🔄 How It Works

```text
Android App
     │
     │ Wi-Fi Command
     ▼
  ESP8266
     │
     │ Control Signal
     ▼
 Relay Module
     │
     ▼
  💡 Light
```

The user presses the **ON/OFF button** in the Android application. The command is sent through Wi-Fi to the **ESP8266**, which controls the relay module to switch the light **ON or OFF**.

## 🎯 Project Objective

The main objective of this project is to create a simple wireless system for controlling a light remotely using an Android application and ESP8266.
